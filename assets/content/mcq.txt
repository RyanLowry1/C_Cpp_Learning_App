# ============================================================== C BASICS
@q b.01
topic: basics
q: Which format specifier prints an `int` with `printf`?
a: `%f`
*a: `%d`
a: `%c`
a: `%s`
why: `%d` is for integers, `%f` for floats and doubles, `%c` for a single character and `%s` for strings.

@q b.02

@end
*a: 3

why: Both operands are `int`, so this is **integer division** - the fractional part is simply thrown away (truncated), giving 3.
