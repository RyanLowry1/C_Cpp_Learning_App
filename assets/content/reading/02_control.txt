# if, else if, else
An `if` runs its block only when the condition is true (non-zero). Chain `else if` to test several conditions; **only the first true branch runs**.

```
int score = 85;
if (score >= 90) {
    printf("Grade: A\n");
} else if (score >= 80) {
    printf("Grade: B\n");
} else if (score >= 70) {
    printf("Grade: C\n");
} else {
    printf("Grade: F\n");
}
```

```output
Grade: B
```

> Order matters. If you tested `score >= 70` first, an 85 would get a C.

## Combining conditions
```
int age = 30;
if (age >= 18 && age <= 65) {
    printf("You are of working age.\n");
}
if (age < 13 || age > 65) {
    printf("Discount ticket!\n");
}
if (!(age > 100)) {
    printf("Probably human.\n");
}
```

- `&&` needs **both** sides true.
- `||` needs **at least one** side true.
- Both **short-circuit**: `a != 0 && b / a > 1` never divides by zero, because the right side is skipped once the left is false.

!> `if (x = 5)` is an assignment, not a test - it sets x to 5 and is always true. Use `==` for comparisons.

# switch
`switch` picks a `case` that matches an integer or character value.

```
char grade = 'B';
switch (grade) {
    case 'A':
    case 'a':
        printf("Excellent!\n");
        break;
    case 'B':
    case 'b':
        printf("Good job!\n");
        break;
    default:
        printf("Invalid grade\n");
}
```

- Stacked labels (`case 'A': case 'a':`) share one block.
- `default` runs when nothing else matches.
- `break` leaves the switch.

!> Forget a `break` and execution **falls through** into the next case. With x = 2, `case 2: printf("two "); case 3: printf("three "); break;` prints `two three`.

*> Fall-through tracing is a classic exam question. Follow the code from the matching case down to the first `break`.

===

# while
A `while` loop tests its condition **before** each pass, so the body may run zero times.

```
int count = 1;
while (count <= 5) {
    printf("%d ", count);
    count++;
}
```

```output
1 2 3 4 5
```

!> If nothing inside the loop changes the condition, it loops forever. Forgetting `count++` is the usual culprit.

# do-while
A `do-while` tests **after** the body, so the body always runs at least once. It suits menus and input validation.

```
int number;
do {
    printf("Enter a positive number: ");
    scanf("%d", &number);
} while (number <= 0);
```

> Note the semicolon after `while (...)` in a do-while.

===

# for
A `for` loop puts the three parts of counting on one line: start; condition; step.

```
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
printf("\n");
for (int i = 10; i >= 1; i -= 3) {
    printf("%d ", i);   // 10 7 4 1
}
```

## Nested loops
The inner loop runs completely for **each** pass of the outer loop.

```
for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= row; col++) {
        printf("*");
    }
    printf("\n");
}
```

```output
*
**
***
```

> Count the iterations: an outer loop of 3 around an inner loop of 4 runs the body 3 x 4 = 12 times.

===

# break and continue
- `break` - leave the loop (or switch) **immediately**.
- `continue` - skip the rest of **this** iteration and carry on with the next.

```
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // skip evens
    if (i > 7) break;           // stop after 7
    printf("%d ", i);
}
```

```output
1 3 5 7
```

## The deliberate infinite loop
```
int i = 1;
while (1) {
    printf("%d ", i);
    if (i == 5) break;
    i++;
}
```

`while (1)` never stops on its own - the `break` is the only exit. This pattern is handy for "keep going until the user types quit".

*> Lab-style tasks in Coding Exam 1 (sum of digits, primes, reversing a number, FizzBuzz) are all built from these loops with `%` and `/`. Practise them in the Coding Workbooks.
